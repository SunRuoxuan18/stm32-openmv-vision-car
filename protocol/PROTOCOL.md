# OpenMV -> STM32 UART 协议

## 串口参数

- 波特率：115200
- 数据位：8
- 校验：None
- 停止位：1
- 方向：OpenMV TX -> STM32 RX；两端必须共地

## 帧格式

每帧固定 8 字节，小端设备不需要做多字节字节序处理：

| 偏移 | 字段 | 说明 |
| ---: | --- | --- |
| 0 | `0xAA` | 帧头 1 |
| 1 | `0x55` | 帧头 2 |
| 2 | `command` | `0x01` 为 DRIVE，`0x00` 为 STOP，`0x02` 为 HEARTBEAT |
| 3 | `left` | 有符号 int8，范围 -100..100 |
| 4 | `right` | 有符号 int8，范围 -100..100 |
| 5 | `confidence` | 0..100，视觉置信度 |
| 6 | `sequence` | 每发送一帧加一，溢出后回到 0 |
| 7 | `checksum` | 对偏移 2..6 做 XOR |

`left` 和 `right` 使用二补码有符号字节。例：`-35` 在线路上表示为 `0xDD`。

## 安全行为

- 帧头错误时继续寻找下一个 `0xAA`。
- 校验错误、速度超范围或未知命令不会改变当前电机输出。
- 有效帧计时超过 250 ms，STM32 应调用停车函数。
- `STOP` 命令立即把两轮速度置零。

## 接线建议

OpenMV 与 STM32 的 TX/RX 交叉连接，并连接 GND。不要把 5 V UART 直接接到只容忍 3.3 V 的 STM32 IO；必要时使用电平转换器。电机电源和逻辑电源分开供电，但必须共地。
